Questions.

Can I download it?

Not yet. bleep is still being built. The demo on this page shows how it will work.

Can it approve things in Claude Code or Codex for me?

Only what your rules allow. Out of the box that is tests, lint, file reads, and screenshots it can check against the ask. Push, deploy, delete, secrets and money always wait for you. Every approval goes in a log you can read.

Which AI does it use?

Claude. bleep talks to Claude through Claude Code on your Mac, so it needs no new API key.

Will it ping me all day?

No. Rules filter the noise first. It has quiet hours and a limit on pings per hour. Most checks end with it saying nothing.

Can it send email as me?

Only after you tap yes on the exact message. Reading is free. Sending, moving events and deleting always ask first.

What can it connect to?

Gmail and Google Calendar first. Every source is a connector, so more can plug in later.
