FAQ

Questions.

How do I install it?

Run the command at the top in Terminal. Then press ⌘ Space and type bleep. A short setup connects Claude Code and Google.

What do I need?

A Mac with Apple silicon on macOS 15 or later, and Claude Code installed and signed in. Intel Macs are not supported.

Is it free?

Yes. bleep thinks with your own Claude plan through Claude Code, so its model use counts toward that plan.

What data leaves my Mac?

Your mail, calendar and memory stay on your Mac. When bleep needs to think, it sends only the text it needs to Claude, through Claude Code. There is no bleep server.

Can it approve things in Claude Code or Codex?

Only what your rules allow. Out of the box: tests, lint, file reads, and screenshots it can check against the ask. Push, deploy, delete, secrets and money always wait for you. Every approval is logged.

Can it remind me of things?

Yes. Say "remind me at 7 to call mom" in the chat, or add one in the Reminders tab. It shows a bubble and a Mac notification on time, even in quiet hours.

Can it send email as me?

Only after you tap yes on the exact message. Sending, moving events and deleting always ask first.

Will it ping me all day?

No. Rules filter the noise first. It has quiet hours and a limit on pings per hour. Most checks end with it saying nothing.

What can it connect to?

Gmail, Google Calendar, Google Drive and the files on your Mac are built in. Turn each one on in Settings, Connectors. Add any app with a remote MCP server: paste its URL and sign in.

Can it read files on my Mac?

Only if you turn on Files on this Mac. It reads Documents, Desktop and Downloads, including the text in PDFs. It skips hidden files and keys. Before it runs any command, it shows you the exact command and waits for your yes.

Can I change how bleep looks?

Yes. Open Settings, then Avatar. Pick a buddy, a color and a finish. The menu bar icon changes to match.

How do I uninstall it?

Run brew uninstall --cask bleep, or drag bleep from Applications to the Trash. Delete ~/.bleep to remove its memory and settings.
