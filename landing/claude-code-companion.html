bleep / For Claude Code

A Claude Code companion that approves the safe asks

bleep watches every Claude Code and Codex session on your Mac. Tests pass, lint passes, reads pass. A force push waits for you. Free and open source.

Updated 18 Nov 2026 · by Aviroop Paul, who makes bleep · bleep 0.5.0

Short answer

  • bleep installs hooks in Claude Code and turn notices in Codex, so it sees every session that waits on you.
  • Rules in code, not a model, decide what passes. Tests, lint and reads pass. Push, deploy, delete, secrets and money always wait for you.
  • Every approval is logged. You see the rest in one Agent sessions window with a short summary of each ask.

The problem

You start three Claude Code sessions and walk away. Ten minutes later, two of them sit idle, waiting for you to type yes to npm test. The third wants to git push --force, and that one really should wait for you. bleep tells these apart.

How it works

  1. Hooks. In setup, bleep adds a small hook to Claude Code and a notify command to Codex. You can remove them in Settings, Agents.
  2. Rules. Each ask is checked against ~/.bleep/agent-rules.toml. A command joined with &&, ; or | passes only if every part matches and nothing risky appears anywhere in it. Shell globs always ask.
  3. Screenshots. When an agent asks you to look at a screenshot, bleep can check it against the ask and let it continue if it matches.
  4. You. Anything the rules cannot read safely comes to you, with a short summary, in the chat and the Agent sessions window.

Questions

How do I auto-approve safe Claude Code permission prompts on Mac?

Install bleep and let setup add its Claude Code hook. bleep then approves asks that match your rules (tests, lint, reads) and holds everything else for you. The rules live in ~/.bleep/agent-rules.toml.

Is this safer than Claude Code's own allow list?

It adds checks. bleep looks at every part of a joined command, refuses shell globs, and keeps a deny list for secrets and risky commands that wins over any allow rule. It also logs every approval.

Does bleep use my Claude plan for approvals?

No. Approvals are decided by rules in code, so they cost no model calls. Only the chat, check-ins and screenshot checks use the model.

Does it work with Codex?

Yes. bleep installs a turn notice for Codex and shows those sessions next to Claude Code.
