One message, start to end

  1. I text bleep on WhatsApp, or send a voice note or photo.
  2. WhatsApp delivers it, end-to-end encrypted, to every device of bleep's account. The Mac's sidecar is one of them.
  3. The sidecar decrypts it and passes it to Rust as one JSON line.
  4. The WhatsApp channel drops other senders, joins quick bursts, turns voice into text and handles /commands.
  5. The Hub starts a turn in the one chat session and remembers that it came from WhatsApp.
  6. The runtime (Claude Code or an API key) thinks and calls tools.
  7. The gate runs read tools at once and turns write tools into a card. The card goes to the phone as a poll and to the Mac. The first answer wins. The reply goes back the same way, with "typing" while it works.
