# Phase 9: Bring your own key

Branch `phase-9-byok`, cut from `settings-sidebar-and-display` (PR 17), because both change Settings. Rebase on main after PR 17 merges.

## Goal

In Settings, pick a **provider** and a **model** for each tier (main, small). bleep then runs its own agent loop with an API key. Claude Code stays as one of the choices. Done when: with Claude Code signed out, an OpenRouter key runs the chat, the 13:00 check-in and an approved email send.

## Design

### Adapter pattern (the standard one)

This is the shape used by the Vercel AI SDK, LiteLLM and LangChain:

- **One loop, many adapters.** `ApiRuntime` implements `AgentRuntime` and owns the loop. It calls a `ModelAdapter` and never looks at a vendor's JSON.
- **Neutral types.** `Msg { role, parts }`. Each part is one of: `Text`, `Image`, `ToolCall { id, name, args }` or `ToolResult { id, ok, text }`. History is stored in this form, so a provider switch keeps the chat.
- **Adapter trait:**
  ```rust
  #[async_trait]
  trait ModelAdapter: Send + Sync {
      async fn stream(&self, req: ModelRequest) -> Result<ModelStream>; // ModelEvent: TextDelta, ToolCall, Usage, Stop
      async fn list_models(&self) -> Result<Vec<ModelInfo>>;            // id, context window, price when known
  }
  ```
- **Two wire formats cover every provider:**
  - `AnthropicAdapter`: the Messages API with SSE. Uses `cache_control` on the system prompt and tools.
  - `OpenAiCompatAdapter`: Chat Completions with SSE. One adapter covers OpenAI, OpenRouter, Gemini (through Google's OpenAI-compatible endpoint), Ollama, LM Studio, Groq and any custom base URL.
- **Provider presets** are data, not code: id, label, wire format, default base URL, whether a key is needed, and a price source.
- **Thin clients, no multi-provider crate.** We need exact control of SSE, usage, rate-limit headers, prompt caching and the fixtures. The two clients are about 300 lines each, on the reqwest 0.12 we already use.

### Tools go through bleep's own MCP server

- `ApiRuntime` is an MCP client (rmcp, already a dependency) of bleep's own server, using `SessionConfig.mcp`. It lists the tools and calls them there.
- So the approval gate, remote connectors and untrusted wrapping stay exactly as they are. The loop gets nothing new to trust.
- A tool call waits while a card is open, so it has no short timeout.
- Max 8 steps per turn, then a final text-only call.

### Sessions

- New table `api_messages(conv_id, seq, msg_json)`. `resume_id` is the `conv_id`; an unknown id is a `StaleResume`.
- The runtime id is `"api"`, so chat sessions per runtime work as they do now.

### `one_shot` (triage, compaction, screenshot check)

- It uses a forced tool call: one tool named `answer` with `input_schema = schema` and `tool_choice` set to that tool. It works on both wire formats and on most OpenAI-compatible servers. Images are sent as image parts.

### Switching without a restart

- `SwitchRuntime` wraps `RwLock<Arc<dyn AgentRuntime>>` and implements `AgentRuntime`. Settings swaps the inner runtime, and every user of `Arc<dyn AgentRuntime>` (chat, triage, compaction, agent watch) follows.

### Config and secrets

```toml
runtime = "api"              # "claude" | "api"
[api]
provider = "openrouter"      # preset id
base_url = "https://openrouter.ai/api/v1"
main = "anthropic/claude-sonnet-4.5"
small = "anthropic/claude-haiku-4.5"
daily_cap_usd = 1.0
```

- **Keys:** stored in the Keychain at `api:<provider>:key`, never in config or logs. One key per provider, so switching back keeps the old key.
- **Claude Code:** keeps `[tiers]` (sonnet/haiku/opus aliases).

### Cost and the cap

- **Prices:** OpenRouter's `/models` gives the price. For Anthropic, OpenAI and Gemini, a small built-in table covers common models. Ollama and LM Studio cost $0. An unknown model shows "no estimate".
- **Recording:** each call writes a row to the `api_usage` table (day, provider, model, tokens in, cached tokens, tokens out, cost).
- **Cap:** when today's cost reaches the cap (default $1), proactive work stops for the day: check-ins, mail triage and the screenshot checks. Chat still works and shows one line saying so.
- **Activity:** shows "Today: $0.12 of $1.00", with a cost per row where known.

### Settings: a new "Model" page (first in the list)

- **Engine:** Claude Code (subscription) or API key.
- **API key fields:** provider select, key (password field), base URL (filled in from the preset, editable), main model and small model.
  - The model fields are combo boxes filled from `list_models`, and you can also type an id.
  - Context window and price show under each model.
- **Buttons:** "Test" sends one tiny call and shows OK, the reply time and the cost. "Save" checks first, then swaps the runtime.
- **Claude Code:** main and small pick from opus / sonnet / haiku.

### Errors

- **429:** `RateLimited { until }` from `retry-after` or the provider's reset headers.
- **401/403:** health shows "Key rejected", and chat says to open Settings.
- **Network and 5xx:** retryable `Error`, with one retry with backoff for an idempotent first call.
